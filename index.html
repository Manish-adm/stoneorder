Setup Steps

1. Open Apps Script from your Google Sheet.
2. Paste the provided Code.gs file.
3. Deploy as Web App: Execute as Me, Access Anyone with the link.
4. Copy Web App URL and paste it inside this HTML: const WEB_APP_URL = 'YOUR_URL_HERE'.
5. Host this HTML on GitHub Pages / Hostinger / local browser.
